# Supported ISP editions

The public ParseISP.jl documentation currently covers the ISP 2024 workflow.

| Capability or published evidence | ISP 2024 |
| --- | --- |
| Report and source download | Supported as part of the 2024 build workflow, with selected report-download support. |
| Archive extraction | Integrated into the ISP 2024 source workflow. |
| Parser integration | Implemented in ParseISP.jl. |
| Build a ParseISP dataset | Implemented by `ParseISP.build_ISP24_datasets`. |
| Generated-output contract | Static and schedule tables are documented for the 2024 build. |
| Published validation evidence | Release-specific validation pages cover supported 2024 sources and outputs. |
| Published analysis or EDA evidence | Release-specific analysis pages interpret supported 2024 sources and outputs. |

These labels describe ParseISP support and published evidence, not the completeness of the upstream ISP release.

Use the [ISP 2024 overview](isp2024.md) for the source-to-dataset workflow.

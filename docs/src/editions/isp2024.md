## ParseISP 2024 workflow

ParseISP implements a data-construction workflow for the 2024 Integrated System Plan.
`ParseISP.build_ISP24_datasets` reads the supported inputs, applies the package's parsers and mappings, and writes static asset tables and time-varying schedule tables.

New users should begin with the [Quickstart](../quickstart.md) to install ParseISP.jl, build one short date range, and check representative outputs.
The [preprocessing workflow](isp2024-preprocessing.md) explains source preparation, static construction, schedule overlays, optional build-outs, and output writing.
The [output tables](../generated/isp2024/reference/output-tables.md) page defines the generated dataset and its joins.
The [parameters and mappings](../generated/isp2024/reference/parameters-and-mappings.md) page records package-defined conventions that affect interpretation.

## Reading the generated data

The static tables describe assets and their comparatively stable attributes.
The schedule tables describe selected quantities that vary by scenario and time.
Interpret a schedule alongside the corresponding static table and its scenario and date fields rather than as a standalone asset inventory.

The [working with ParseISP-generated outputs](../generated/isp2024/tutorials/working-with-pisp-outputs.md) tutorial demonstrates this relationship with a selected 2024 build.
The validation and analysis sections of the ISP 2024 documentation provide release-specific checks and exploratory context for those sources and outputs.

## Scope

The 2024 workflow is a data-preparation step for downstream power-system studies.
It does not itself run dispatch, unit commitment, capacity expansion, or power-flow models.
See [assumptions and scope](../assumptions.md) before treating generated data as study-ready.
